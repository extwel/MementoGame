# 🎮 MementoGame

**MementoGame** — 2D RPG-игра в жанре тёмного фэнтези, разработанная на языке программирования Java с использованием паттерна проектирования **Memento (Снимок)**.

## 📖 О проекте

MementoGame — это игровое приложение, в котором игрок исследует игровой мир, сражается с противниками, собирает монеты и проходит игровые уровни.

Главная цель проекта — продемонстрировать практическое применение паттерна проектирования Memento для сохранения и восстановления состояния игры.

## ✨ Основные возможности

- Передвижение персонажа и боевая система.
- Искусственный интеллект и атаки противников.
- Анимация персонажей.
- Несколько игровых уровней.
- Сбор монет и внутриигровой магазин.
- Экраны победы и поражения.
- Система сохранения и загрузки игры.
- Несколько слотов сохранения.

## 🛠 Используемые технологии

- **Java** — основной язык программирования.
- **IntelliJ IDEA** — среда разработки.
- **Git** — система контроля версий.
- **GitHub** — хранение исходного кода проекта.

## 🧩 Паттерн проектирования Memento

В проекте используется паттерн **Memento (Снимок)**, который позволяет сохранять и восстанавливать внутреннее состояние игры без раскрытия её внутренней реализации.

### Основные компоненты паттерна

| Класс | Назначение |
|---|---|
| `Game` | Originator — создаёт и восстанавливает состояние игры. |
| `GameState` | Хранит данные сохранённого состояния игры. |
| `Memento` | Сохраняет снимок состояния игры. |
| `SaveManager` | Caretaker — управляет сохранением и загрузкой. |
